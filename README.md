# Anushka — Online Food Delivery

A responsive food delivery storefront built with HTML, CSS, and vanilla JavaScript. Browse dishes by category, search the menu, and add items to an interactive cart.

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.

## Features

- Responsive food menu with category filters and live search (`⌘ K` / `Ctrl K`).
- Food cards with add-to-cart controls.
- Slide-out cart with quantity controls and a live subtotal.
- Accessible buttons, labels, and cart status updates.

Food photography is loaded from Unsplash; Google Fonts are used for typography.
